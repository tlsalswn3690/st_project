## 방법
회귀 · 군집 · 연관 중 하나. 왜 이 방법인지 한두 문장. 연관 분석:  위생 실천율과 감염 발생률 사이에 어떤 관계가 있는지 알아보기 위해 연관 분석을 선택하였다. 손 위생 실천율이 높아질수록 감염 발생률이 낮아지는 경향이 나타나는지 데이터를 비교하고자 한다. 
분석 과정(실제로 한 일, 단계마다 무엇을·어떻게·왜): 1. 데이터 수집 : CDC의 손 씻기 교육에 따른 질병 감소 통계와 병원 내 손 위생 실천율 및 의료 관련 감염 발생률 연구 자료를 수집한다.
2. 변수 선택 : 손 위생 실천율, 의료 관련 감염 발생률, 질병 종류별 감소율을 분석 변수로 선정한다.
3. 전처리 : 자료마다 다른 단위와 측정 기준을 확인하고, 백분율(%)로 통일하여 표로 정리한다
4. 분할: 병원 내 손 위생 실천율과 감염 발생률 자료를 기준으로 기간별 데이터를 구분하여 비교한다. 
5. 기준선: 전체 기간의 평균 손 위생 실천율과 평균 감염 발생률을 계산하여 비교 기준으로 삼는다.
6. 후보 모델 비교 : 산점도, 상관계수 분석 등 여러 방법을 활용하여 변수 사이의 관계를 비교한다.
7. 선택 :손 위생 실천율과 감염 발생률의 관계를 한눈에 확인할 수 있는 산점도와 상관계수 분석을 선택한다.
8. 평가 :  상관계수의 크기와 방향을 확인하여 손 위생 실천율과 감염 발생률 사이의 관계를 평가한다.
9. 해석: 손 위생 실천율이 높아질 때 감염 발생률이 낮아지는 경향이 있는지 확인하고 간호사의 감염 예방 역할과 연결한다.
10. 한계 점검 : 조사 대상과 기간, 병원 환경 등에 따라 결과가 달라질 수 있으며, 상관관계만으로 손 씻기가 감염 감소의 직접적인 원인이라고 단정할 수 없다는 점을 고려한다.
